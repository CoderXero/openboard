# Keyboard shortcuts

`Ctrl+N` creates a project, `Ctrl+O` opens one, `Ctrl+S` saves, `Ctrl+Shift+S` saves as, `Ctrl+Z` undoes, `Ctrl+Shift+Z` or `Ctrl+Y` redoes, `Delete` removes the selection, and `Ctrl+D` duplicates it. Tools use `V` select, `P` pen, `E` eraser, `R` rectangle, `O` ellipse, `L` line, `A` arrow, `T` text, `N` sticky note, `M` mind map, `F` frame, and `H` hand/pan. Hold `Shift` or the middle mouse button while dragging to pan.
